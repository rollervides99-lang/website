Project highlights

Modeling and validation at the center.

Dakota uses ensemble learning and systematic model evaluation to generate robust equity signals with measurable out-of-sample performance.

XGBoost architecture

My XGBoost model consists of 300 sequential regression trees. Each tree has a maximum depth of four and attempts to correct the prediction errors remaining from the previous trees. The learning rate limits each tree to 5% of its proposed adjustment, and the model minimizes squared error to produce a predicted next-quarter log return using RMSE.

LightGBM robustness

LightGBM uses a similar gradient boosting framework, with each tree trained on 90% of observations and 80% of features. This randomness reduces overfitting, while Huber loss adds robustness to extreme residuals and supports more stable predictions for equity return forecasting.

Meta learner

The meta learner synthesizes base model outputs and is tuned using RMSE to prioritize predictive accuracy. It blends the signal from XGBoost and LightGBM into a consolidated prediction that improves confidence for next-quarter return estimates.

OOF validation

Out-of-fold validation is applied to the SGB and LGB models only. OOF ensures each observation is evaluated on a model that was not trained on it, which is critical for measuring true generalization and preventing overfit in the gradient boosting stacks.
